## 1. P0 · 必测（本轮改动最重的行为面）

### 1.1 剧情对话全回合（对应：T1.3 roleplay_node 拆解 + T2.2-B3 会话加载 + B4 持久化）

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 进入任一有卡作品，发送一条剧情消息 | 正常流式回复；`<status>`/表格/纪要照常出现，无原始控制块泄漏 |
| 2 | 回合结束后**刷新页面**再回到该对话 | 历史完整加载（含图片/状态卡），开场白不重复、已删消息不复活 |
| 3 | 切到**创作平台（home）**，再切回该作品 | 消息不丢不重；切回后 1–2 秒内恢复完整（B3-b 会话加载链） |
| 4 | 连续快速发送 2–3 条消息 | 逐条排队/回复，顺序不乱（B4 持久化 600ms 防抖合并后仍不丢消息） |
| 5 | 发一条触发自动高潮锚点/事件判定的消息 | `<roll>`/`<fate>` 等块被正常消费为状态卡，正文干净 |

**失败取证**：刷新后消息缺失 → 记录作品名 + threadId；`agent-trace.jsonl` 末尾最后一个 `roleplay` 事件的输出段；console 是否有红色错误。

### 1.2 自动插画（对应：T2.2-A 插画提交链整体外移 useIllustrationChain）

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 触发一轮自动插画（剧情走到带 `<illustration>` 的回合） | 前台立刻收到正文与插画请求（正文先行，不被插画阻塞） |
| 2 | 观察插画落位 | 图片按 `messageId + slotId` **原位回填**，不追加新消息轮、不错位到别的消息 |
| 3 | 插画生成期间**切换到别的对话再切回** | 插画完成后仍回填到原消息原槽位 |
| 4 | 生成期间点**停止/导航离开** | 无「已取消却仍落图」或「图挂起永不回填」 |

**失败取证**：截图「错位/丢失的图片消息」；ComfyUI 队列页截图；`agent-trace.jsonl` 中 `illustration` 相关事件段；浏览器 console。

### 1.3 画布运转链（对应：T2.1 CanvasStageFlow 六刀——投影/事件订阅/覆盖层全拆过）

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 打开作品画布，拖动几个节点后刷新 | 节点位置/选中态保留（C 刀投影 + mergeProjectedNodes 原坐标保留） |
| 2 | 右键节点/空白处 | 右键菜单正常弹出、项齐全（D2 CanvasContextMenu） |
| 3 | 双击各类型灵感卡（剧情/工具/参考图/世界书/主卡） | 五类弹窗分别正确打开、能编辑保存（D1/D2 覆盖层拆分） |
| 4 | 点节点卡框进单节点视图，回画布，再进另一节点 | 无「ComfyUI 未加载完误判」「卡框显示别的工作流」回归（对应此前修过的两个 bug） |
| 5 | 挑一个模板**真运转**一次（需 ComfyUI 在线） | 占位节点出现→进度更新→终态清除；结果图落在正确节点 |
| 6 | 运转中**另开一个标签页**打开同一画布 | 无同 id 双节点、无画布空白（`N:x [0]` 现象） |

**失败取证**：`laf-canvas-wf-*` 事件链相关 console 输出；截图画布（重点拍节点 id/占位）；运转的 template 名。

### 1.4 会话加载三级兜底（对应：T2.2-B3 useSessionLoad 246 行整链）

| # | 步骤 | 预期 |
|---|------|------|

## 4. 失败取证统一格式（出问题时给 agent 这些）

1. **现象一句话**：页面/对话/画布哪个，点了什么，期望什么实际什么。
2. **作品名 + threadId**（对话类）/ template 名（画布类）。
3. **`backend/data/logs/agent-trace.jsonl` 末尾 200 行**（脱敏后贴或交路径）。
4. **浏览器 console 全量红色错误**（F12 → Console，右键 Save as… 存文件）。
5. **截图**：错误弹窗 / 错位的图片消息 / 画布异常节点。
6. **时间点**（精确到分）——便于对 Trace 轮转文件。
