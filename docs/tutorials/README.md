# Demiurge 教程（Tutorials）

> 面向终端用户的入门与进阶教程。README 只保留最短可用路径，复杂解释全部放这里，
> 每篇按统一模板撰写：用途 → 前置条件 → 操作步骤 → 参数解释 → 正确结果 → 常见错误 → 排查入口。
>
> 应用内还有一套可交互的新手引导（启动后首次进入会展示，也可随时重新打开），
> 它与本目录互补：引导覆盖「每步点哪里」，教程补充「为什么会这样、出错了去哪查」。

## 规划中（依据真实界面与运行结果补齐，未完成前不开放链接）

- 大仓库、小仓库与作品绑定（含分支与反事实实验）。
- 工作流模板创建：暴露参数、语义标注、能力描述与提交前验证。
- 生图参数选择：提示词 Profile、Checkpoint、采样器、画幅与 Latent 换算。
- 节点知识库与缺失节点：同步、索引、插件安装与更新。
- AI 搭工作流：从自然语言目标到可运行模板。
- LoRA 同步与角色绑定：single / multi / none 三档模式的差异。
- 自动插画进阶：高潮点 / 首尾帧、错角色与错 LoRA 排查。
- 角色卡、世界书、预设与正则：SillyTavern 导入与编辑模式。
- RAG、数据表、纪要与资产语义搜索。

## 校验与反馈

教程依据真实界面与运行结果撰写。发现界面变化导致步骤失效，或某步「正确结果」与
实际不符，请在 [GitHub Issues](https://github.com/Carmenangle/Demiurge/issues) 反馈，
并尽量附上界面截图与错误信息。
