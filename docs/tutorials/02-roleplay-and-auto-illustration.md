# 教程 02 · 第一条剧情与自动插画

- **用途**：绑定角色卡与世界书，让剧情高潮点**自动**生成图片 / 视频 / 音频，
  生成结果原位回填到对应剧情段落，不打断对话。
- **前置条件**：已完成[快速开始](01-quick-start.md)的模型与路径配置；
  已导入至少一个标注了提示词字段的工作流模板（纯文本剧情可跳过模板，但不会有自动插画）。
- **预计耗时**：10 分钟（不含生成等待）。

## 1. 创建作品并绑定角色卡

首页集中了仓库、角色卡、世界书入口：

1. 点击左上角新建仓库（大仓库）与其中的小仓库（作品）。
   新建小仓库时会弹出「仓库绑定」，直接选择角色卡即可——角色卡内嵌的世界书在导入时
   已外拆为同名独立世界书，绑卡后自动加载。
2. 也可从首页「角色卡」入口卡，或资产管理里一键从角色卡建作品。

**正确结果**：进入对话界面后，上方功能栏出现比默认更多、与角色卡能力对应的功能项
（说明角色卡与世界书导入成功）；刚进入就有开场卡决定的初始对话。

## 2. 挂世界书与偏置预设（可选）

「仓库绑定」弹窗里：

- 独立世界书可另挂别的书；不绑则自动用与角色卡同名的世界书。
- 偏置预设选本作品专属预设；留空则用全局激活预设。
- ST 格式预设从首页「预设」入口卡导入：片段可开关、可拖动排序——越靠后越接近
  生成点、遵守越强。

## 3. 开始剧情对话

直接输入继续剧情。默认「剧情模式」：

- 只带上一次剧情轮的正文作为历史，控制上下文。
- 角色会**自主行动**（NPC 能动性），尝试失败也会写成未遂或受挫，而不是静默消失。
- 正文中模型会输出 `<status>` 战报（在场、所在等），系统随回合写回**角色状态**，
  并自动维护**数据表与纪要**；值得长期保留的新知识由 Curator 沉淀进世界书与知识库。
- 这些维护内容不占对话正文字数，也不显示在聊天气泡中。

## 4. 打开多元数据面板

点对话上方功能栏的「多元数据插入」按钮。面板自上而下四块：

### 4.1 生成类型

生成图片 / 生成视频 / 生成音频三个开关，可多选（至少勾选一项）。
保存预设会自动开启「剧情自动生成」——之后每个剧情高潮点按勾选类型分别生成。

> 视频没有独立素材来源：它用图片分区里每个角色的底图作**首帧**。
> 想自动出视频，先配好图片分区（4.2 的角色底图）。

### 4.2 角色外貌来源（二选一）

- **条目模式**：合集卡玩法（主要角色写在世界书条目中）——从当前小仓库世界书
  命中的角色视觉条目读取外貌。
- **角色卡模式**：多角色卡 + 一本世界书的玩法——从本作品绑定的角色卡描述读取外貌，
  适合纯机制世界书。

每个在场角色可配置：角色名（与剧情中一致）+ 角色 LoRA 与权重 + 底图。
若某角色既无 LoRA 也无底图、且无兜底风格，面板会红字提示该角色出图缺少一致性锚点。

### 4.3 LoRA 模式（三档）

| 模式 | 行为 | 模板要求 |
|------|------|---------|
| 无 LoRA | 只用角色底图，不加载角色或风格 LoRA | 模板无需标注 LoRA 字段 |
| 单 LoRA | 每角色一个 LoRA；无专属 LoRA 的角色落「兜底风格 LoRA」 | 必须标注 LoRA 字段 |
| 多 LoRA | 固定加载默认风格 LoRA + 叠加全部在场角色 LoRA | 必须标注 LoRA 字段 |

### 4.4 提示词模式与出图方式

提示词模式按生图模型选：ComfyUI 本地生成建议 **Anima**（质量行 + 内容 tags /
英文描述，可固定质量词与负面词）；**GPT Image / Banana** 之类 API 生图选自然语言；
**Niji** 出图选 Niji（主体 / 风格 / 附加 / 后缀）。

出图方式二选一：

- **高潮点模式**：在唯一视觉高潮处出单张定格图。
- **首尾帧模式**：按剧情首帧 + 尾帧生成、全程覆盖剧情与对白；此时视频自动变为
  **首尾帧剧情影片**（含本段全部对白）。

「智能模态」开启后：剧情动作剧烈（奔跑、律动等）时自动改用视频模板，静态画面仍出图。

音频模板（IndexTTS 系语音合成）要求：必须标注「角色台词」（voice_text）才能保存；
建议再标「参考音轨」（voice_reference）启用音色克隆——每角色一条参考音轨，
台词按角色筛分逐角色合成，旁白 / 叙述句不配音。

## 正确结果

- 提交剧情后，正文先行返回；高潮点的媒体槽随后出现在对话中并**原位回填**，
  不追加新对话轮、不阻塞你继续输入。
- 已完成回合生成数据表、纪要与角色状态的自动维护；切换页面后任务继续在后台运行。
- 想手动验证实际加载的 LoRA：看该次提交的 Trace 与 ComfyUI 工作流，
  而不是只看提示词里写了什么。

## 常见错误

| 现象 | 原因与处理 |
|------|-----------|
| 没有自动出图 | 未开「剧情自动生成」；或该轮没有视觉高潮；或工作流模板没标提示词字段 |
| 出图但角色不像 | 外貌来源选错（条目/角色卡）、角色底图缺失、LoRA 未绑定或权重过低 |
| 角色 LoRA 完全没生效 | LoRA 模式与模板字段不匹配；从 Trace 确认实际加载的 LoRA 文件名 |
| 视频首帧不对 | 视频用图片分区底图作首帧——先配好 4.2 的图片底图再出视频 |
| 音频没人声 / 全部合成 | 台词字段未标注（无法注入）；旁白不配音是预期；参考音轨缺失时无音色克隆 |
| 后台任务一直不结束 | 看「后台活动」面板与 ComfyUI 队列；必要时重新生成该槽 |

## 排查入口

- 界面步骤与截图：应用内「新手引导 → 剧情扮演」。
- 生成失败定位：对话内提交 Trace、「系统管理 → 节点管理」的 ComfyUI 状态与
  「后台活动」面板。
- 角色卡 / 世界书字段与导入细节：应用内「编辑模式」与角色卡编辑器。
- 还查不到？到 [GitHub Issues](https://github.com/Carmenangle/Demiurge/issues) 提交。
