# 教程 01 · 快速开始：从下载到第一张图

- **用途**：完成 Demiurge 的首次安装与配置，导入一个 ComfyUI 工作流模板，
  并在剧情对话里跑通第一次图片（视频 / 音频）生成。
- **前置条件**：一台 Windows x64 / macOS ARM64 / Linux x64 电脑。
  只使用云端生图模型时不需要本地 ComfyUI；本教程按最常见的「本地 ComfyUI」路线写。
- **预计耗时**：15–30 分钟（不含首次下载 ComfyUI 模型权重）。

应用内每一步都有对应截图，可打开「新手引导 → 快速开始」对照操作。

---

## 1. 下载与启动

1. 在 [GitHub Releases](https://github.com/Carmenangle/Demiurge/releases) 下载名称包含
   `00-USER-DOWNLOAD` 的、与你平台匹配的 **Full RAG** 包。
2. 解压后按平台启动：

| 平台 | 启动 | 关闭 |
|------|------|------|
| Windows x64 | 双击 `start-dev.bat` | 双击 `stop-dev.bat` |
| macOS ARM64 | 双击 `Start-Demiurge.command` | 关闭启动终端或停止对应进程 |
| Linux x64 | 运行 `start-demiurge.sh` | 关闭启动终端或停止对应进程 |

3. 等待浏览器自动打开 `http://127.0.0.1:8010`（便携包）/ `http://127.0.0.1:5173`（源码开发）。

**正确结果**：浏览器打开工作台首页；Windows 终端能看到后端与前端进程均已启动。
**常见错误**：双击后无反应、或浏览器打开后页面持续空白——多为解压路径含中文/空格、
或首次运行被安全软件拦截；换纯英文目录解压后重试，必要时右键「以管理员身份运行」。

> 终端用户包已内置 Python Runtime、后端、构建后的前端、Chroma/BM25、Torch、
> Transformers 与 SentenceTransformers，不需要另装 Python、Node.js、pip 或 npm。
> ComfyUI、模型/LoRA 权重、Embedding/Reranker 权重与用户素材不随包分发，需在下一步配置。

## 2. 配置模型（设置 → 模型）

「⚙ 设置 → 模型」添加模型卡：

1. 填 **API URL**（如 `https://api.openai.com/v1`）。
2. 填 **API Key**。
3. 填 **API 模型名称**，可点「读取模型列表」直接选择。
4. 按接口协议选 **Provider Profile**（OpenAI 兼容 / Claude 兼容——按协议选，不按模型名选）。
5. 点「测试模型」确认连通后保存。

- **对话模型**必配（剧情推理与维护都靠它）。
- **生图 / 视频 / 嵌入模型**按需分别添加；本地嵌入或 GGUF 可在对应卡片切 local 模式。

**排查入口**：测试失败先核对 URL、Key 与模型名拼写；自建网关 / 代理时确认
「设置 → 代理」里的代理配置与协议一致。

## 3. 配置路径（设置 → 路径）

「⚙ 设置 → 路径」填写：

- **ComfyUI 目录**：含 `main.py` 的 ComfyUI 文件夹。
- **ComfyUI 访问地址**：如 `http://127.0.0.1:8188`。
- **仓库文件夹**：生成图片与会话记录都落在这里。
- **角色卡 / 世界书 / 偏置预设文件夹** 与 **工作流默认读取路径**：素材从哪读。

目录决定素材从哪读、产物存到哪；保存后会在下次启动时自动拉起 ComfyUI。

## 4. 确认 ComfyUI 运行

`start-dev.bat` 会按第 3 步保存的配置自动启动 ComfyUI（已在运行则跳过），
首次初始化约 30–60 秒。在「系统管理 → 节点管理」查看状态，显示「● 运行中」即可。

两个例外需要手动：刚填完路径还没重启过后端、或自动拉起失败时，在「节点管理」
右上角点「启动」手动拉起。只用云端生图模型可跳过本步（不填 ComfyUI 目录就不会自动启动）。

## 5. 导入工作流模板（最短路径）

「工作流管理 → 工作流模板」：

1. 点「选择文件导入」导入一个 ComfyUI 导出的工作流 JSON（.json），
   或点「扫描默认目录」批量导入。
2. 进入模板编辑：勾选要暴露给剧情调用的节点参数——**提示词必标**，建议再标
   负面提示词、Latent 宽高、LoRA 字段、角色底图槽位（规则见下文「参数解释」）。
   也可以切到 ComfyUI 界面模式，在内嵌画布上长按节点按顺序选择。
3. 填「模板名称」，必要时用「编写能力描述」指定 AI 可干涉的输入/输出节点，点「保存模板」。

**正确结果**：模板出现在列表并可被对话侧 `/w` 唤起。
**常见错误**：

| 现象 | 原因与处理 |
|------|-----------|
| 保存失败，提示必须标注提示词 | 该工作流没有可注入剧情提示词的入口；换含正向提示词节点的模板 |
| 画布载错 / 节点对不上 | ComfyUI 界面模式下点「重新载入画布」 |
| 生成的图没套用角色 LoRA | LoRA 字段未暴露；single/multi LoRA 模式必须在面板标注 LoRA 字段 |

## 6. 用 `/w` 调用并生成第一张图

1. 回到作品对话，输入 `/w`，在弹出的模板选择里选定模板。
2. 按模板暴露的顺序填参：提示词、宽高、LoRA、图片输入口等。
3. 提交：生成中的媒体槽在对话中占位，完成后图片/视频/音频**原位回填**，不新增对话轮。

**正确结果**：对话里出现占位媒体槽 → 完成后替换为真实生成结果，
且这条生成记录不占用正文字数、不阻塞你继续输入下一轮。

## 参数解释（最短可用集）

- **提示词（prompt）**：剧情注入点，工作流模板**必须**标注此字段，否则无法保存模板。
- **负面提示词**：只在要用固定负面词时标注。
- **Latent 宽 / 高**：不标注则对话里的 1K / 2K / 4K 尺寸不会注入工作流。
- **LoRA 字段**：单 LoRA / 多 LoRA 模式必须标注，否则角色 LoRA 不生效。
- **角色底图槽位**：图生图锁角色一致性时标注；纯文生图可不标。
- **Seed / 采样器等其余参数**：继承工作流原值，不需要每次填写。
