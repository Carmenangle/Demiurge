# 导入工作流模板（选择节点暴露参数）

> 模板的作用：把一个 ComfyUI 工作流变成「可对话调用」的生成器——导入工作流 → 选择暴露哪些节点参数
> （提示词、宽高、LoRA、图片输入口……）→ 保存后即可在对话 / 画布中直接调用，无需再碰工作流本体。

**前置条件**：已启动并连接 ComfyUI；如使用「扫描默认目录」批量导入，请先在「设置 → 路径」中配置工作流默认读取路径。

---

## 步骤 1：进入模板页并导入工作流

打开「工作流管理 → 工作流模板」，两种导入方式任选：

- **「选择文件导入」**：单个导入工作流 JSON 文件；
- **「扫描默认目录」**：批量导入默认目录下的全部工作流（未配置路径时会提示先到「设置 → 路径」配置，或直接改用「选择文件导入」）。

> 💡 通过 AI 搭工作流生成的工作流也会保存到该目录，点「扫描默认目录」即可看到并继续配置。

📷 **截图 1**：工作流模板页——包含「扫描默认目录 / 选择文件导入 / 新建模板」按钮与「已保存模板」列表

![工作流模板页：扫描默认目录 / 选择文件导入 / 新建模板](../assets/guide/quick-start-5.png)

## 步骤 2：新建模板，进入模板编辑

点 **「新建模板」**（或从扫描结果中选择一个工作流进入编辑），进入模板编辑页。页面顶部可在两种编辑模式间切换。

📷 **截图 2**：模板编辑页——两种方式选暴露参数（参数清单模式 / ComfyUI 界面模式）

![模板编辑：两种方式选暴露参数](../assets/guide/quick-start-6.png)

---

## 步骤 3：选择要暴露的节点参数（两种模式）

### 方式 A · 参数清单模式（适合结构清晰的工作流，推荐快速配置）

- 在参数清单里**勾选**要暴露的节点参数——常暴露：**提示词、宽高、LoRA、图片输入口**；
- 已连线的字段不可暴露；
- 系统会**自动推断语义绑定**（prompt / lora / latent / 负面词等），也可手动修改 label 与默认值。

📷 **截图 3**：参数清单模式——勾选要暴露的参数（含语义绑定列）（暂见上方截图 2 插图）

### 方式 B · ComfyUI 界面模式（适合复杂工作流，推荐）

- 页面内嵌**真实 ComfyUI 画布**，在画布上**长按节点**即可选中；选中后会自动带入该节点全部可编辑参数；
- **列表顺序即 AI 对话提供节点的顺序**（后续在对话里按此顺序为节点填参）；
- 画布加载不对？页面会自动检测并重载纠正——另开的 ComfyUI 标签会抢占画布、载入成别的工作流（部分节点载入后被隐藏属正常，不影响判定）；若仍不对，**关掉其他 ComfyUI 标签后点上方「重新载入画布」**即可。

📷 **截图 4**：ComfyUI 界面模式——画布中长按选择节点（含「重新载入画布」按钮）（暂见上方截图 2 插图）

---

## 步骤 4：保存模板（含 AI 干涉范围与主输出节点）

填写 **「模板名称」** → 点 **「保存模板」**（重新编辑已保存模板时按钮显示为「更新模板」）。

在模板的 **「编写能力描述」** 里还可以指定三类节点：

- **替换输入节点 / 替换输出节点**——这是 **AI 可以干涉的范围**：对话 / 画布调用模板时，AI 只往「替换输入节点」填参（左侧接线 / 自身参数），只从「替换输出节点」取结果（右侧接线，流入下游）；范围之外的内容 AI 不会动；
- **主输出节点**——**默认不需要选择**（未设置时取所有输出节点产物）。如果工作流有多个输出、用模板生成的结果不合料想（比如取到了副产物的图），再回到这里**手动指定**主输出节点即可。

![编写能力描述：替换输入 / 输出节点与主输出节点](../assets/guide/quick-start-7.png)

保存完成后，即可在对话 / 画布中直接调用该模板：对话中只需提供暴露参数的值（如提示词、宽高），系统按模板组装工作流提交 ComfyUI 出图。

---

## 常见问题

| 现象 | 处理 |
|------|------|
| 「扫描默认目录」扫不到文件 | 到「设置 → 路径」确认工作流默认读取路径；或直接「选择文件导入」 |
| 界面模式画布载入的不是本模板工作流 | 关掉其他 ComfyUI 标签（画布被抢占），再点「重新载入画布」 |
| 参数清单里找不到想暴露的字段 | 该字段可能已被连线（已连线字段不可暴露）；或切换「ComfyUI 界面模式」长按该节点整节点带入 |
| 想调整 AI 对话填参顺序 | 界面模式下按选择顺序即对话提供顺序，重新按顺序长按选择即可 |
| 生成结果不是预期的产物 | 到「编写能力描述」手动指定主输出节点（默认未设置时取所有输出节点产物） |

# 在对话中调用模板（/w 快捷指令）

> 模板保存后不用离开对话流：输入 `/w` 即可调用，按提示填参、运转、出图一气呵成。

## 步骤 1：输入 /w 选择模板

回到作品对话，直接输入 **`/w`**，即可弹出模板选择提示；选定要使用的模板。

📷 **截图 5**：对话中输入 `/w` 后的模板选择提示

![对话输入 /w 调用模板](../assets/guide/quick-start-8.png)

## 步骤 2：按节点顺序填参

选定模板后，会按模板选择的节点顺序展示各节点暴露的参数，逐项填写（提示词、宽高、LoRA、图片输入口等）。

📷 **截图 6**：`/w` 选定模板后的节点参数展示效果

![按节点顺序填参](../assets/guide/quick-start-9.png)

## 步骤 3：运转工作流

提交后工作流开始运转，生成中的媒体槽已在对话中占位；完成后图片 / 视频 / 音频在对话内原位回填，不新增对话轮。

📷 **截图 7**：工作流运转并出图（媒体槽回填效果）

![运转工作流，媒体原位回填](../assets/guide/quick-start-10.png)
