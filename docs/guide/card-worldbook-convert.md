# 固化流程：角色卡世界书转化

> 把 ST/通用角色卡的内嵌世界书外拆为独立世界书。
> 与[固化流程：批量生图](./curing-process.md)/[小说转合集卡](./novel-to-collection-card.md)同源——这一篇专注「卡内嵌书外拆」。

本篇是应用内新手引导「固化流程：角色卡世界书转化」板块的 GitHub 阅读版。

## 1. 设置路径（首步前提）

「⚙ 设置 → 路径」里填好「角色卡文件夹」与「世界书文件夹」并保存——后面导入时系统就会把卡内嵌世界书外拆到世界书文件夹（同名独立世界书）。没填的话卡内嵌书不会被外拆，会跟着卡走、不进入世界书条目管理。

要点：

- 两份目录都是源库目录，与作品快照隔离。
- 「世界书文件夹」只决定外拆后的落盘位置；外拆动作本身由导入能力触发，不在 UI 里手动执行。

## 2. 导入角色卡（自动外拆）

「资产管理 → 角色卡 → 导入角色卡」选一张 ST PNG/JSON（或通用 JSON 卡）。后端走 `character.import_source` 能力（`extract_worldbook=true`），按规范 §1 把卡本体按 TavernCard V1/V2/V3 解析落源库，同时把内嵌世界书外拆为兄弟 `worldbook.json`（运行时真源），并从卡里清掉 `character_book`。落盘形态是**卡目录三文件**：`card.json` + `worldbook.json` + `regex.json`。

要点：

- 导入后卡变干净（`has_worldbook=false`），同名独立世界书出现在「世界书」列表。
- 下次「仓库绑定」选这张卡时会自动加载这本书（同名的源库世界书优先）。
- PNG 是二进制：`import_source` 直接读字节解析 tEXt 内嵌卡，无需手工导出 JSON。

## 3. 也可对话式精细转化

想筛掉条目、改 keys、合并或拆分时，把卡（PNG/JSON）拖入智能编造对话，指令「按固化知识库《固化03-ST迁移规范》§3.2 把这张卡的内嵌世界书独立出来」。Agent 会按规范给计划（含哪些条目留下、哪些合并、keys 是否重写），批准后落盘。

要点：

- 对话式转化的「计划」会列出每条保留/丢弃/合并的意向，逐条可审。
- 想在作品快照里同时挂多本书时（角色卡自带一本，再额外挂一本机制书），在「仓库绑定」里勾两本分别绑定即可——同名源库世界书自动挂，额外的另选一本。
